# YEGNA BINGO V51.1 — Hotfix notes

This archive contains targeted fixes applied to the supplied V51 source. It is a test candidate, not a claim of production certification.

## Changes in this hotfix

- Telegram Bot deposit/withdrawal conversation lookups and updates consistently use the Telegram numeric ID for the database key. Callback-query handlers use the raw Telegram user's `id`; handlers that receive a database user row use `telegram_id`.
- Telegram Bot ETB amount input accepts positive decimal amounts with at most two fractional digits and correctly grouped optional thousands separators. It rejects malformed grouping, zero/negative values, and excessive amounts.
- Telegram Bot prompts and confirmation messages use actual line breaks instead of displaying literal `\\n` text.
- The Node HTTP server caps request bodies at 1 MiB and returns HTTP 413 for oversized requests.
- API routes reject malformed JSON and non-object JSON bodies with HTTP 400 rather than treating malformed JSON as an internal server error.
